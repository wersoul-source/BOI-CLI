# Get Started with BOI CLI

See the [README](README.md) for the quick start guide.

**TL;DR** — 3 steps:

```bash
# 1. Download from GitHub Releases → extract → place in PATH

# 2. Configure providers (interactive TUI wizard — asks count first, then arrow-key select)
boi setup

# 3. Launch!
boi
```

That's it. BOI CLI handles the rest — persona selection, chat, command palette, memory, and provider auto-fallback.

For detailed documentation, see:
- `docs/` — CLI commands, architecture, build plan
- `/help` in TUI — keyboard shortcuts and commands
